### Q1. What is `origin/main`, and when is it wrong?

`origin/main` is a remote-tracking branch. It records where the remote main branch was the last time I fetched or communicated with the remote. It can be out of date when someone pushes new commits and I have not run `git fetch` or `git pull`.

### Q3. Why was force-push acceptable in Task 7.6?

The branch was in my own fork, and nobody else was relying on its commits. Rebasing changes commit hashes, so the local branch and remote branch can differ and a normal push may be rejected. `--force-with-lease` is safer than a plain force-push because it checks that the remote has not changed unexpectedly. On a shared branch, force-pushing could overwrite other people's work, so it should be avoided.
